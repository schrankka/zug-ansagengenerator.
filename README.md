# Zug-Ansagengenerator: Bahnsteig + im Zug

Enthaltene Dateien:
- `index.html` – Auswahlseite
- `bahnsteig.html` – nur Bahnsteigdurchsagen
- `im-zug.html` – nur Ansagen während der Zugfahrt
- `style.css` – gemeinsames Design
- `common.js` – Browserstimme, synthetischer Gong, Kopieren und TXT-Export

## Auf GitHub Pages veröffentlichen
1. Erstelle ein Public Repository auf https://github.com, z. B. `zug-ansagengenerator`.
2. Entpacke die ZIP-Datei und lade alle fünf Dateien ins Hauptverzeichnis hoch.
3. Öffne Settings → Pages.
4. Wähle `Deploy from a branch`, Branch `main`, Ordner `/(root)`, dann Save.
5. Nach der Veröffentlichung findest du die URL unter Settings → Pages.

Die Stimme hängt vom Browser und Gerät ab. Der Gong wird elektronisch erzeugt und ist keine Originalaufnahme. Es gibt keine Echtzeitfahrplandaten und keinen MP3-Export; Ansagetext kann als TXT gespeichert werden.
